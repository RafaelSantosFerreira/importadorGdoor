Preço de venda

Não insere produtos e não altera nenhum outro campo.

Casa cast(CODIGO as int) = cast(id_identificador as int) (004152 = 4152) e grava PRECO_VENDA a partir de prc_venda, só onde os dois estão diferentes.

Buscar não altera nada. Preço 0 no CSV contra preço maior que zero no banco aparece marcado na lista, mas nunca é gravado. Códigos que não existem no banco são só listados.

Saldo em estoque

Não insere produtos e não altera nenhum outro campo.

Casa cast(CODIGO as int) = cast(id_identificador as int) e grava QTD a partir de qtd_atual, só onde os dois estão diferentes. QTD_SALDO e QTD_DISPONIVEL são calculados pelo banco a partir dela.

Buscar não altera nada. Quantidade negativa no CSV aparece marcada na lista, mas nunca é gravada.

Faltando no banco

O CSV é a referência; nada é gravado.

Percorre o CSV e lista os id_identificador que não têm CODIGO correspondente no ESTOQUE (cast as int nos dois lados).

Lista todos os faltantes, com a linha do arquivo. Para cadastrar, use o card abaixo.

Inserir faltantes copiando produto do mesmo NCM

INSERT … SELECT a partir de um produto modelo.

Para cada código do CSV que não existe no banco, copia o produto ativo de maior CODIGO com o mesmo COD_NCM, trocando CODIGO, DESCRICAO, BARRAS, PRECO_VENDA e o saldo (QTD; o QTD_SALDO é calculado pelo banco) pelos valores do CSV. DATA_CADASTRO vira a data de hoje.

Prévia não altera nada. Sem produto com o mesmo NCM, o item fica de fora e aparece no log; digite na coluna Modelo o código de um produto para copiar e rode a prévia de novo. Qualquer erro: nada é gravado.
